# Flight Price Prediction Project

## Datasets
Download and unzip the datasets from Kaggle:

- Expedia flight data: https://www.kaggle.com/datasets/dilwong/flightprices/data  
- Airline reviews: https://www.kaggle.com/datasets/juhibhojani/airline-reviews

## Project Structure

The project is divided into two R notebooks:

DataPreparationPropre.Rmd — Handles all data preparation steps: cleaning, handling missing values, outlier removal, feature engineering, and merging datasets.
AnalysisNoteBook.Rmd — Contains the analysis and modeling: exploratory data analysis, visualization, clustering, and price prediction.
